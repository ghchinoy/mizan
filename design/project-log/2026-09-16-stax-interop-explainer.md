## Review outcome and finalization

review-l1-docs APPROVED the page with zero Critical/Required (accuracy
byte-verified against the golden tests, SSOT clean, zero dashes, all six areas
present). Two follow-ups were folded into a single finalization push:

1. **Category-naming prose tightened** to exactly match the exporter guard in
   `internal/staxexport/staxexport.go` (`categoriesForScale` / `slug`): a band is
   anchored only when its `RatingRubric` description is present and slugifies to a
   non-empty token, named `{band}-{slug}` (lowercased, non-alphanumeric runs to
   single hyphens, trimmed). No-description, blank, and slug-empty cases all fall
   back to `score-{band}`.
2. **model_id owner ruling applied (fail-closed omit-when-unset).** When
   `--model-id` is unset the exporter omits the field entirely (not `""`), so
   Stax rejects with a clean `@NotNull` 400. This matches the merged
   `docs/user-guide.md` note and spec §6.3. All worked examples supply an explicit
   `--model-id`, so the behavior does not appear in any example.
