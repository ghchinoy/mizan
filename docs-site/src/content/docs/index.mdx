## Core Capabilities

<CardGrid stagger>
  <Card title="Typed Decision Primitives (boul, choice, score)" icon="approve-check">
    Answer software's three core evaluation questions without hand-rolling JSON schemas: **`boul`** for binary pass/fail propositions with confidence, **`choice`** for grammar-constrained categorical routing, and **`score`** for calibrated continuous grading. [How the primitives work →](/mizan/blog/03c-three-typed-primitives/)
  </Card>
  <Card title="Pointwise, Rubric, Pairwise & Custom Schema" icon="list-format">
    Run Vertex AI `EvaluateInstances` **pointwise** metrics, multi-criterion **rubric** scorecards (with `--rubric-detail`), head-to-head **pairwise** (`BASELINE` / `CANDIDATE` / `TIE`) comparisons, and arbitrary **`custom_schema`** structured output.
  </Card>
  <Card title="Multimodal Across Five Modalities" icon="laptop">
    Evaluate **text, images, audio, video, and music** with the same template contract. Pass `--file key=/path/to/asset` (auto-staged to your configured GCS bucket) or `--gcs key=gs://...` for pre-staged objects.
  </Card>
  <Card title="SQLite Provenance, Packs & Agent Skills" icon="document">
    Every run persists its inputs, template snapshot, score, and explanation to a pure-Go SQLite store (`mizan results list|show`). Share standards via Git-native packs (`mizan pack init|add|validate`, `mizan registry import|export`), `mizan mcp`, and [Agent Skills](/mizan/guides/agent-skills/).
  </Card>
</CardGrid>

## Quickstart Workflows

<Tabs>
  <TabItem label="Typed Primitives (boul, choice, score)">
    Install Mizan, configure your Vertex AI project, and run a strongly-typed boolean check with zero custom JSON schema boilerplate:

    ```sh
    # 1. Install the CGO-free Go binary and set your GCP project
    go install github.com/ghchinoy/mizan/cmd/mizan@latest
    mizan config set project-id <your-project-id>

    # 2. Register a typed boolean proposition check (boul)
    mizan registry create --id safety/pii-check --name "PII Check" \
      --kind boul \
      --prompt "Does this customer message contain unmasked PII or credit card numbers? {{message}}"

    # 3. Evaluate an input (persisted automatically to the local results store)
    mizan eval run --metric safety/pii-check \
      --field message="My phone is 555-0199 and card is 4111-2222-3333-4444"
    ```
  </TabItem>

  <TabItem label="Template Packs & Sharing">
    Scaffold, author, validate (credential-free), and import shareable YAML metric packs:

    ```sh
    # 1. Scaffold a new pack namespace and export a local metric into it
    mizan pack init packs/acme-support --name acme-support
    mizan pack add packs/acme-support --from acme-support/reply-quality

    # 2. Run the credential-free structural + placeholder validation gate
    mizan pack validate packs/acme-support

    # 3. Preview and import a pack into your local SQLite registry
    mizan registry import packs/acme-support --dry-run
    mizan registry import packs/acme-support
    ```
  </TabItem>

  <TabItem label="Agent Skills & Structured JSON">
    Drive Mizan from Claude Code or any `-o json`-aware coding agent using the shipped plugin marketplace:

    ```sh
    # Structured JSON output on stdout for scripts and skills (proven by drift tests)
    mizan eval run --metric safety/pii-check \
      --field message="Order #4821 shipped via UPS Ground." -o json

    # Inspect stored evaluation runs and full provenance
    mizan results list --limit 10 -o json
    mizan results show <run-id>
    ```
  </TabItem>
</Tabs>
